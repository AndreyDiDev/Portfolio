# Portfolio

Source for my personal site: https://andreydidev.github.io/Portfolio/

Plain HTML, CSS and a little JavaScript, no build step. Open `index.html` in a browser to preview.

- `index.html` – the whole page
- `assets/css/style.css` – styles (light and dark follow the OS setting)
- `assets/js/main.js` – mobile menu, section highlighting, image zoom
- `assets/img/` – photos and plots

The previous SvelteKit version is in the git history.
